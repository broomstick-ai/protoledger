# letta-code / writer-current

- **Origin:** synthetic, **generated by running Letta Code's own writer**,
  `appendTranscriptDeltaJsonl` in `src/cli/helpers/reflection-transcript.ts` of
  https://github.com/letta-ai/letta-code at `69b7f82c91558a95a85c28cf59a1a194b3af5817` (v0.34.16+4), under Bun
  1.3.14 on 2026-10-17, with `LETTA_TRANSCRIPT_ROOT` pointed at a scratch dir.
  Input: two turns of scripted accumulator `Line`s (ids shaped like the real
  generators: `user-<base36>-<6>`, `message-<uuid>`, `toolu_…`, `err-…`),
  including a split assistant line, a failed and an interrupted tool, an
  unfinished tool and an `event` line the writer drops. The writer also
  produced `state.json`.
- **License:** data is ours (CC0); letta-code is Apache-2.0.
- **Sanitised:** nothing to sanitise.
- **Exercises:** the current row shape (`source_line_id` + `source_message_id`),
  one `captured_at` per turn, reasoning/assistant sharing a message id,
  tool rows with and without results, error rows, the `state.json` sidecar.
